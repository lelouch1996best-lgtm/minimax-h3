# 剧集目录整理规则

用于规范分集短剧项目（如「宫装女友」类系列）的目录组织，确保同一剧集只有一个目录、编号连续、同类资产归位。

## 核心规则

- **一个剧集 = 一个目录**。同一剧集的所有分段（A/B/C/D）必须放进统一的剧集目录，不允许 `E015合集` 与 `E015A`、`E015B` 平级并存。
- **目录按集数连续编号**：`E01`、`E02` … `E15`，不因分段产生跳号或额外目录。
- **分段只体现在文件名前缀**（如 `宫装女友E15A_*.mp4`），不体现在目录层级。
- 整理目标对齐已有的正确范式：分段文件平铺在剧集目录内（参照单段剧集及多段合集剧集的既有结构）。

## 标准剧集目录结构

```
E<编号>-<剧名>/
  images/      场景图、参考图、尾帧
  video/       成片、分段成片、抽帧、封面候选
  BGM/         背景音乐（可选）
  voice/       配音/原声（可选）
  剧本/         该集剧本
  提示词/       各分段生成提示词
  任务记录/      payload / submit / result / run-state 等任务文件
  E<编号>-发布文案.txt（可选）
```

## 如何识别"待整理"模式

出现下列任一情况即需整理：

1. 同时存在 `E<N>-...合集/` 与 `E<N>A-.../`、`E<N>B-.../` 等同级目录。
2. 同一集内容被拆到多个以字母后缀命名的目录中。
3. 目录编号不连续，缺失的编号实际以"分段目录"形式存在。

不属于本规则、**不要改动**的情况：

- 合集目录**内部文件名**沿用了其他编号（如某上下集合集内部出现下一集编号字样的文件），属于历史命名，且文件确属该合集，保持原样以免破坏引用。
- 单段独立剧集内部结构正常、无同级重复分段目录。

## 合并操作流程

1. **盘点**：列出主目录与各分段目录的全部文件，按 `images / video / BGM / voice / 剧本 / 提示词 / 任务记录` 归类。
2. **干跑预览**：先生成"移动 / 跳过 / 待删目录"清单，确认无误后再实际执行，禁止未预览直接改动。
3. **平移归位**：把分段目录中的文件移入剧集主目录的**同名子目录**，文件名保留（文件名已自带 A/B 前缀，天然唯一）。
4. **根目录散落文件**（如 `E15-refs.json` 及其 `.state.json`）移到剧集主目录根，保持原名。
5. **清理空壳**：全部移动完成、确认无遗漏后，删除空的分段目录。

## 同名冲突处理

- **内容完全相同**（用 MD5/哈希校验一致）：判为重复，只保留主目录中的一份，其余跳过。
- **同名但内容不同**：给后并入的文件加上分段前缀/后缀，例如 `t8balance-E15B-...`，严禁覆盖。
- **多分段共用的状态文件名**（如 `t8balance-run-state.json`）：按分段重命名为 `E15A-t8balance-run-state.json`、`E15B-t8balance-run-state.json`。
- 拿不准是否重复时，按"保留两份、加前缀区分"处理，不删除任何疑似独有资产。

## 安全准则

- 只移动/归类，不修改文件内容；不删除任何成片、剧本、提示词、任务记录。
- 移动前确保目标子目录存在；跨目录移动优先用原子重命名。
- 整理后复查：剧集目录数量应等于最大集数、编号连续；每个分段成片都能在对应剧集目录中找到。
- 临时整理脚本放在临时工作目录，执行完即清理，不污染项目目录。

## 整理示例

整理前（错误）：

```
E015-争宠夜话合集/      (仅合集与拼接记录)
E015A-争宠夜话·献茶/    (图、视频、任务记录、剧本、提示词)
E015B-争宠夜话·撒娇/    (图、视频、任务记录、提示词)
```

整理后（正确）：

```
E015-争宠夜话合集/
  images/   E015A_*.png, E015A_tail.jpg, ...
  video/    E015.mp4, 宫装女友E015A_*.mp4, 宫装女友E015B_*.mp4, 抽帧...
  剧本/      E015-争宠夜话-剧本.md
  提示词/    E015A.md, E015B.md
  任务记录/  ...E015A-*.json, ...E015B-*.json, E015A-t8balance-run-state.json, ...
```
