# 接口与配方参考

## 一、图床上传（WorkBuddy 资料库组件）

**为什么需要它**：MJ 的 `sref` 只接受公网 URL，不接 base64 / 本地路径。图床是唯一中转。

```
POST /space/api/agent/v1/upload-image
Req : { data: <base64>, contentType?: "image/jpeg", fileName?: "sref.jpg" }
Rsp : { url: "https://…/image/xxxx.jpg", width: 1536, height: 864 }
```

调用方式（由 `tone_lib.upload_image()` 封装）：

```bash
python "<config.upload_script>" "<本地图片绝对路径>"
# stdout: KS_IMAGE_UPLOAD_OK {"url":"https://…","width":1536,"height":864}
```

限制：单文件 ≤ 10 MiB（客户端提前拦截）；扩展名须在 `png/jpg/jpeg/gif/webp/bmp/svg/heic/heif/tiff` 内。sref 源按长边 1536 / JPEG q90 压，实测约 300 KB。

## 二、65535 出图（基准图生成 / 图生图）

```
POST https://task-api-1-cn.65535.space/v1/tasks
Authorization: Bearer $S65535_API_KEY
{
  "kind": "image",
  "model": "gpt-image-2.5-flare",
  "input": {
    "prompt": "…",
    "size": "16:9", "resolution": "2k", "n": 1,
    "image": ["data:image/jpeg;base64,…", …]   // 图生图时给；文生图省略此字段
  }
}
→ { "id": "task_xxxx" }

GET /v1/tasks/{id}   轮询，status ∈ {done, failed}，取 result_urls[0] 下载
```

- **图生图 vs 文生图唯一区别**：`input.image` 传不传。
- 多参考图分工要写进提示词：如「第 1 张定空间 / 第 2 张定人物」，模型按传入顺序理解。
- 参考图在内存里压到长边 1536 / JPEG q86 后转 base64，不落中间文件。

## 三、MJ sref 出图（定调链）

```
POST https://api.apib.ai/v1/midjourney/generations
Authorization: Bearer $APIMART_API_KEY
{
  "prompt": "…", "negative_prompt": "…",
  "sref": "https://…/image/xxxx.jpg", "sw": 500,
  "version": "7", "size": "16:9", "quality": "2", "speed": "fast"
}
→ { "data": [{ "task_id": "…" }] }

GET /midjourney/{task_id}
→ data.status ∈ {success, failed}
   data.grid_image_url       九宫格（带 MJ 水印式网格）
   data.image_urls[0..3]     4 张单图
```

**参数**：`sw 500`（风格权重中高：影调继承充分而不过度锁死内容）、`version 7`、`quality 2`、`speed fast`。若某镜影调继承不足，可把 `sw` 提到 600–700。

**日志备注**：APIMart base 用 `https://api.apib.ai/v1`（旧的 `api.apimart.ai` 存在 DNS 污染）。若本机有 7890 代理会自动探测使用。

## 四、「中国电影感古风」六维定义（写法示范）

六维不是形容词堆砌，而是**可直接落进提示词的规格**：

| 维度 | 规格 |
|---|---|
| **色彩** | 低饱和、低对比的「高级灰」基底；全局统一青蓝（teal-blue）+ 冷灰；只在夜明珠光晕与红衣上保留极克制的暖色点缀，形成冷暖微差。不要鲜艳、不要高饱和。 |
| **光影** | 单一光源、大光比、深阴影；光从侧后方斜切（伦勃朗式侧逆光），人物半边脸沉入暗部；光线有明确体积感，空气中有细微雾霭与尘埃。 |
| **质感** | 真实物理材质——岩石的颗粒与凿痕、丝绸的厚重光泽与自然褶皱、皮肤的细腻毛孔。拒绝塑料感与磨皮感。 |
| **影调** | 暗部不死黑、保留细节（lifted blacks）；高光柔和不溢出；整体偏暗、偏闷、有呼吸感的低照度影调。 |
| **镜头** | 电影级大画幅摄影质感；轻微胶片颗粒与柔和微反差；浅景深但背景仍可读。 |
| **参照系** | 当代中国电影摄影（《刺客聂隐娘》《影》一类的实拍质感）——沉静、克制、有物质重量。不是电视剧、不是游戏 CG、不是动漫。 |

## 六、已踩的坑

1. **sref 诱发红色印章 / 书法题字** —— 实测 4 张里 2 张左上角出现脑补的国风印章。与「成片默认不出字幕」红线直接冲突。已进默认负向词，且出图后必须逐张查四角与边缘。
2. **MJ 自行增补场景元素** —— 石室被加进佛像、壁龛浮雕、灯笼、烛台。需在提示词显式声明「只有 X 别无他物」，并把不想要的元素写进负向词。
3. **色调定调 ≠ 定人** —— 基准图里的脸与角色三视图并不完全一致（AI 二次演绎），但 sref 只提取色彩 / 光影 / 质感，不搬运人脸，因此不影响定调用途。**人物身份仍以三视图为唯一基准。**
4. **参考图压缩上限** —— 上传给 65535 的参考图长边 1536 / q86，上传给图床的 sref 源长边 1536 / q90；两者都别超（前者防 token 膨胀，后者防 1 MiB 超限）。
