# 宫装女友热点播报（韩老魔的宫装女友）

一句话流程：trends-hub 抓 B站+抖音热点 → 选适合"女友跟男友唠"的话题（无合适则自创有趣脚本）→ story-craft 写第一人称男友 POV、**带互动节拍**的剧本（女主对镜头/男友索取回应，互动规范见 `references\interaction-playbook.md`）→ 按剧本场景从凡人资源包选女性角色三视图，65535 图生图生成"人物+场景"一体的真人质感参考图 → 交 h3-drama-producer 出片（t8balance、9:16、mp0.86 默认，不内置 BGM；**单片即成品**）→ **仅拆片集/多段组合**才走 Step 5B 拼接与统一 BGM → sau 发布（默认 B 站 + 抖音双平台，**抖音 5 个话题中第 1 个直接用热搜标题原文原样**）。

## 触发条件

用户想做"女友跟你说热点时事"类短视频：说「来一期宫装女友说热点」「抓个热点做女友视频」「女友播报今日热点」「韩老魔的宫装女友更新一期」等，或要求自动化执行"热点 → 女友 POV 剧本 → H3 视频"整条链路时。已有成片时说「发布/同步到 B站/抖音」「双平台发一下」，直接走 Step 7；只要求为已有合成视频选/生成/复用 BGM，直接走 Step 5B；只要求让剧本"别像单口、加强互动"，直接走 Step 3（互动细则按 `references\interaction-playbook.md` 重写该集剧本的互动字段）。

## Step 1 — 抓取热点（trends-hub MCP）

按 MCP 三步协议调用（先 LS 服务器工具目录 → Read 工具 JSON 描述 → run_mcp），服务器名 `mcp_trends-hub`：

| 工具 | 参数 | 说明 |
|---|---|---|
| `get-bilibili-rank` | `{"type": 0}` | B 站全站排行（可换分区：1 动画 / 3 音乐 / 4 游戏 / 5 娱乐 / 160 生活 / 181 影视） |
| `get-douyin-trending` | `{}` | 抖音热搜榜 |

- 两榜并行拉取，合并去重，保留排名与热度值
- 整理 Top 15—20 条热点列表（标题 + 来源 + 热度），作为 Step 2 选题池
- **热搜标题原文逐字登记（2026-09-19 用户指定）**：热点池表必须保留平台、排名、热度与**标题原文**，不润色、不缩写、不改写成近义说法；后续「Step 2 采用项 → Step 6 文案包「热点」行 → Step 7.3 抖音第 1 个话题」全部**从该表原样复制粘贴**。热搜标题是抖音话题的唯一来源，禁止凭记忆或二手转述重写（改写即失去热搜关联，流量入口作废）
- 服务器整体不可用（未接入/未启用）时见「特殊情况」

## Step 2 — 选题（女友唠嗑适配评估）

**评估五维**：情绪可发挥度（能否撒娇/调皮/吃醋地聊）、**互动可发挥度（能否自然引出"向男友发问 / 索要 / 赌约 / 考你"，而不是只能单向播报）**、情侣日常感（真的会跟男友分享吗）、画面可呈现度（单场景 15 秒内可演）、话题安全性。

**排除（不进候选）**：政治敏感、灾难事故伤亡、暴力犯罪、涉未成年人负面、严重社会对立、色情低俗。

**偏好类型与情绪匹配**：

| 话题类型 | 推荐情绪 | 默认互动抓手（对男友做/说的那一下） |
|---|---|---|
| 游戏上线 / 游戏圈 | 兴奋安利、小得瑟 | 抓一下他（拽袖）拉他一起玩：「你今晚陪我打一把」 |
| 影视综 / 明星八卦 | 吃瓜、调皮 | 考他站队：「你说他俩是不是真的？」 |
| 科技数码新品 | 好奇、兴奋 | 安利完顺势索要：「这个你买给我好不好」 |
| 萌宠趣事 | 心疼、软萌撒娇 | 把话题拐到自己身上：「我们以后也养一只嘛」 |
| 美食 | 撒娇求投喂 | 讨投喂：「你喂我一口，就一口」 |
| 文化国风 | 小得瑟科普、傲娇 | 考你式科普：「考考你，这个你知道叫什么吗」 |
| 体育趣闻 | 激动、调皮 | 押注式邀约：「今晚一起看，输的洗碗」 |
| 网络热梗 | 调皮玩梗、傲娇考你 | 玩梗考他：「你懂这个梗吗，别装」 |

- 选出 Top 3—5 候选，附推荐情绪、切入角度、**至少 1 个可执行的互动点**（要写给男友的那一句或那个动作）与**热搜标题原文**（原样附上，供 Step 6 文案包与 Step 7.3 抖音话题直接引用），展示给用户（标注推荐项）；用户无偏好时（含无人值守）直接采用推荐项并说明理由，**同分时优先互动点更硬的那个**
- **两榜均无合适话题（全被排除或情绪无从发挥）→ 自创有趣脚本**，不硬蹭。自创方向示例：修仙界热搜体（"灵界热搜第一：某韩姓老魔又双叒闭关了"）、宫装女友现代初体验系列（第一次点外卖 / 第一次刷短视频）、古风语言聊现代事的反差萌；**自创同样先定"要向男友索取什么"，再套热点外壳**。须向用户说明"今日热点不适配，改为自创"

## Step 3 — 剧本（story-craft）

调用 `story-craft` 技能（Skill 工具，插件全名 `trae-remote-official:story-craft:story-craft`）创作，传入以下定制约束（沿用其人物灵魂设定与反 AI 味文笔体系）：

- **体裁**：甜宠日常短剧本，喜剧向，风格温度 2—3 档
- **视角**：全程第一人称男友 POV，女友单人对着镜头说话（镜头＝男友的眼睛）；男友不露脸、不露躯干、**不发声成句**，只允许非语言反应音（一声"嗯" / 半声轻笑 / 轻吸气）
- **互动（2026-09-19 起为硬要求，本步最重要的一条）**：每段必须是"有来有回"的贴身唠嗑，**不是女友自说自话的单口**；镜头前的人是在跟男朋友说话，不是对着摄像机念稿。互动设计唯一正本＝本技能目录内 `references\interaction-playbook.md`（三档定义 / 节拍结构 / 动作库 / 句式库 / 提示词写法 / 自检清单都在该文件），本步只列硬指标：
  - 每 10s 段 **≥2 个互动节拍**、每 15s 段 **≥3 个**（节拍＝一个明确的"对男友的动作或索取"，不是台词句数）
  - 每段 **≥1 个**向男友发问 / 索取 / 赌约 / 考你；**禁止**"只在最后一句才提到男友"的段
  - 段尾 **1.5s 内必须落回男友**（对视等待 / 索要承诺 / 赌约收束）；**严禁把热点念完就结束**
  - 每段 **≥1 次**身体距离或姿态变化（凑近半寸 / 前倾 / 后仰 / 歪头 / 举高道具），做出"凑到男友面前"的贴近感
  - 问句 **≤2 个/段**；单次留白 **0.3—0.8s**；全段留白 **≤1.5s**
  - 互动档位按 playbook §2 定，**默认 L1 邀请式 + L2 求回应式**（女友对镜头索取回应，男友一声"嗯"/轻笑入声并触发女友即时接招）；**L3 越界式**（男友手/前臂边缘入画）**须用户明确批准**，剧本阶段即标注
  - 拆片集段间为**接力互动**：上段把问题抛给男友 → 下段开场承接（如"你刚才是不是偷偷笑我了？"）
- **人物**：宫装女友一名（角色由 Step 4 定），按凡人 IP 人物性格做角色卡
- **对白**：中文口语、软糯甜妹感，单集 3—5 句（15 秒内自然说完）；热点信息像唠嗑一样自然带出，**禁止新闻播报腔**；句式优先取 playbook §6 互动句式（邀请 / 确认在场 / 追问 / 赌约 / 索要 / 赌气 / 考你 / 收束），其中**至少 1 句来自"追问 / 赌约 / 索要 / 收束"四类**（只堆"邀请"仍会退化成单口）
- **情绪**：按 Step 2 匹配结果（撒娇 / 调皮 / 吃醋 / 好奇 / 兴奋安利 / 小得瑟 / 心疼 / 吃瓜 / 傲娇，可组合）
- **场景**：暖光室内（闺房 / 卧室 / 书房），与宫装造型协调，单场景不转场
- **结构**：四拍——起（引入热点＋向男友献宝）→ 展（情绪展开）→ 逗（加压：撒娇 / 吃醋 / 考你 / 赌约，把话头抛给男友）→ 收（索要承诺或等回应，落点在男友身上）；单片时长 10—15 秒按节奏定（对白按约 4—5 字/秒估算容量，15s 约 60—70 字）；超过 15s 容量按固定约定「编号硬规矩」拆片

### 5B.3 get-music 生成新 BGM

### 5B.4 混音合成

**拼接 + 混音已固化为 `tools/concat_and_mix.py`**（2026-09-19 E11 起固化）：`--segs` 按剧情顺序传各段、`--bgm` 传曲库文件，自动完成 concat 流拷贝（失败转码兜底）→ BGM 短于成片时 `aloop` 循环铺满 → 垫底混音（默认 volume=0.25、淡入 0.5s、片尾淡出 1.6s，均可调）→ ffprobe/volumedetect 校验 → `merge_summary.json` 落盘，一条命令完成 5B.1+5B.4。手工执行时注意：

系统 PATH 的 ffmpeg 为精简版（缺 aac 编码器），取完整版：`python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"`

- **输入**：拆片集用 `E{NN}_拼接.mp4`（合集目录 `video\`）；单片直接用原始成片 `宫装女友E{NN}_时间戳.mp4`（本集 `video\`，无拼接件）

```powershell

  -filter_complex "[1:a]volume=0.25[bgm];[0:a][bgm]amix=inputs=2:duration=first:dropout_transition=0[a]" `
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k `
  "<输出>E{NN}.mp4"
```

- **产出统一命名 `E{NN}.mp4`**（发布版惯例，沿用 E01）：落**合集目录** `E{NN}-{关键词}合集\video\`；**单片集不产混音版**（发布用原生成片，见 Step 7.0 成片行）。E08 实际产物名为 `宫装女友E08_秋日火锅合集.mp4`，属订正期历史例外不回改，新集一律 `E{NN}.mp4`
- BGM 音量 0.2—0.3（人声与环境音为主、BGM 垫底）；`duration=first` 保证输出不超视频时长
- 新生成的 BGM 已带淡入淡出（`--trim`）；复用曲库且时长超出视频时先 `--trim` 重截或滤镜补 `afade`

- **Step 7 发布用件**：**拆片集/多段合集**用混音版 `E{NN}.mp4`；**单片集**用原生成视频 `video\宫装女友E{NN}_时间戳.mp4`（无 BGM）

### 7.3 抖音话题 5 个硬上限 + 热搜标题原样做话题（重点防坑）

- 每条作品**最多 5 个话题实体**。传 6 个以上时，前 5 个正常变蓝，第 6 个起编辑器不再转换，且话题联想弹层/IME 会把后续中文打成乱码（如 `#AI视频 #宫装女友…` 变 `#A#I#G#宫#搞#沙修仙同人…`），这是平台限制不是输入抖动，加重试/放慢打字都无效
- **话题构成（固定 5 个）**：① **热点话题＝Step 1 抓到的热搜标题「原文原样」**（字面复制：一字不改、不缩写、不换近义说法、不自造词；这是流量入口，改写即丢热搜关联）② 剧名 1 个（韩老魔的宫装女友，系列沉淀）③ IP 名 1—2 个（凡人修仙传 / 角色名）④ 品类泛标签 1 个（AI短剧 / AI视频）
- **热搜标题取词规则（原样优先，只做机械处理，不改词）**：
  - 标题含空格：**只去掉空格**，字号字序不动（抖音编辑器以空格结束话题输入，带空格会把后半截变成普通文本）
  - 标题含 `·`、`｜`、`：`、`，` 等分隔符：取分隔符前的完整主段，或去掉分隔符后连成一体；仍不可用时取标题中最长的完整短语
  - 标题超过约 20 字：在词边界截取**完整前半短语**，宁短不造词
  - 原题被平台拒（敏感词）或完全无可搜索性：退化为**原题中的核心原词**（仍是原词，不改写），并在台账注明「热搜标题未原样采用 + 原因 + 实际用词」
  - 标题原文只能取自 Step 1 表格（含平台与热度）；**文案包「热点」行与抖音第 1 个话题必须字面一致**，发布后回读核对，不一致按编辑页修复路径处理
- **文案包书写格式（脚本解析硬要求）**：抖音话题在该集《E{NN}-双平台发布文案.txt》的 `## 抖音` 块内写成**编号列表**，每行 `N. #话题名`（N 从 1 起，第 1 条为热搜标题原文）。`publish_episode.py` 按此格式抽取并按序提交（兼容单行 `#a #b #c` 与逗号串，但**规范格式只有编号列表**）；写成其它形式会被解析为空 → 抖音以**零话题**发布（E11 文案包原为单行写法，已按本条修订为编号列表并作为首个规范先例；该集尚未发布，故未造成实际损失）
- **B 站侧（建议非强制）**：把热搜标题原文作为第 1 个标签（B 站标签允许含空格），其后接剧名 / IP / 品类，共 10—12 个
- 已发布作品若话题已乱码：可走作品编辑页修复（`https://creator.douyin.com/creator-micro/content/post/video?mid={aweme_id}&enter_from=edit_item`，从内容管理点「编辑作品」是同标签页跳转），用 patchright 清空 contenteditable（`div.zone-container[contenteditable="true"]`）后 **`keyboard.insert_text()` 粘贴整段（绕过 IME）**，只保留 5 话题，点「提交修改」，等「修改成功」toast，再回读 API 确认。老的 `/web/api/media/aweme/modify/` 接口已失效（返回 "Url doesn't match"），只能 UI 改
