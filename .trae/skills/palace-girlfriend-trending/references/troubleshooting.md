# 异常速查 · 处置与降级

出问题先查本表，按"处置"执行；涉及脚本参数细节回到对应参考文件。

## 热点源

| 情形 | 处置 |
|---|---|
| 两榜全敏感/负面 | 全部排除转自创脚本，不硬蹭（Step 2） |
| B站/抖音单接口失败 | 换 trends-hub 其他榜（get-weibo-trending/get-toutiao-trending）并说明 |
| trends-hub 整体不可用 | 报告用户接入；goal/无人值守转自创方向，台账注「热点源不可用」 |

## 参考图（Step 4）

| 情形 | 处置 |
|---|---|
| `S65535_API_KEY` 缺失/报错 | 请用户配置或查 65535 技能，不硬编码；临时故障稍后重试 |
| 上游审核拒绝 upstream_error | gen_refs.py 自动重试链（改措辞→同角色换造型→换角色）；全败转 4.5 双参考（ref-generation.md） |
| keyframe 提示 WAIT（参考图缺失） | 正常的依赖保护而非报错：确认 scene 已落盘（路径与 JSON 一致）后，原命令重跑即可补齐，断点续跑不会重复生成 |
| 身份走样 | 加强身份锁定、重新编码三视图重生成 |
| 场景不符 | 场景段写具体陈设光线 |
| 有文字拼贴 | 构图段强调单人画面、非三视图排版、无文字 |
| 美颜/CG/影棚感 | 真人质感段与反向约束段完整照抄基准（点名瘦脸大眼/磨皮/极端虚化/影棚光/过度HDR），不得精简 |
| 连续 2 次非审核失败 | 兜底：images 旧图选场景最接近一张（提示词补环境），或走 4.5 双参考；向用户说明降级 |
| 用户要求跳过生成直接出片 | 允许用旧图/三视图，提示场景错配风险并记台账 |
| 参考图与画风冲突 | 按 h3-drama-producer 画风闸门；4.5 双参考属预设授权路径，按其强制抽帧不走闸门 |

## 剧本与互动（Step 3）

| 情形 | 处置 |
|---|---|
| 互动不足（单口/段尾不落男友/无索取） | 按 playbook §9 五问定位缺陷段，回炉重写互动结构（非改词） |
| 剧本未变但成片平淡 | 按 playbook §7 修订提示词重出该段 |
| 成片出现第二人 | 不合格：改回 L1+L2、删手部措辞重出；L3 每次必抽帧 |
| 临时加互动但不重写剧本 | 可提示词层补 L1（怼机/对视/停顿），告知效果弱并记台账「仅提示词层补强」 |

## 出片（Step 5）

| 情形 | 处置 |
|---|---|
| t8balance OOM/FAILED | 升 ultra 重跑；仍败报用户，可换 t8lite（画幅差异须确认） |
| 余额不足 | 展示费用估算（video-production.md §5.8），充值后再提交 |
| 费用未批准 | 确认卡等批准；无人值守 update_goal(blocked) |

## BGM（Step 5B）

| 情形 | 处置 |
|---|---|
| 因内置 BGM 需整片重出 | 重出无 BGM 版（推荐），件名加 `_NM`/`_NM_nobgm` 后缀，旧件保留，费记「可避免浪费」 |
| 单片被要求加 BGM | 说明规矩（BGM 线只服务多段组合）；坚持则书面批准后 concat_and_mix.py 单段混音产 E{NN}.mp4，台账注「单片例外」 |
| 曲库无合适曲/get-music 不可用 | key 缺失/余额/域名（api.apib.ai 可直连）/失败时报用户；可先交无 BGM 拼接版，到位后幂等重跑 |
| BGM 生成提交失败 | 不重发 POST，new_music.py `--query <task_id>` 幂等补查 |

## 编号

| 情形 | 处置 |
|---|---|
| 同剧本误占多号 | 目录改名（段目录加 A/B + 建合集目录）+ 两台账订正；历史文件名与 taskId 保留不动 |

## 发布（Step 7）

| 情形 | 处置 |
|---|---|
| sau cookie invalid | 走 sau-upload 登录/CDP 修复，不反复重发 |
| B站投稿 SSL 报错 | bldsa 证书过期，改 `--line bda2` 直连 |
| B站创作声明 -1/None | 投稿漏带或误用 --submit app；用全局脚本重投或 set-decl 兜底 |
| 删误投/测试稿 | bili_publish.py `delete --aid`（回读 state=-100） |
| 抖音弹短信验证 | **硬暂停**：停回合索码、goal 先 blocked；无 BOM 写 verify_code.txt；码失效重新获取 |
| 抖音页面卡死/弹窗不渲染 | 停进程换有头或无头重发；先 API 查重防发两遍 |
| 抖音话题乱码 | 超 5 个所致；编辑页 insert_text 重写 5 话题 |
| 零话题/话题未生效 | 文案包非编号列表→改编号列表；未发改文案包重跑，已发编辑页修复并注「首发零话题」 |
| 热搜标题含空格/分隔符断词 | 按取词规则只做机械处理（去空格/取主段），不改词，注明实际用词 |
| 热搜标题过长/被拒 | 退化为原题核心原词，台账注明原因与实际用词 |
| 发布进程 exit code 1 | Bad file descriptor 可忽略，以日志+API 回读判定 |
| 用户提前发布定时稿 | 定时失效不重复发；API 回读确认，台账记手动发布 |
