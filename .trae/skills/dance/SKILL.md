# 韩老魔歌舞团·舞蹈复刻（两条路径：动作迁移 / 提示词反推）

## Step 0 — 路径选择门（每次开工先做，不可跳过）

本技能有两条出片路径，**开始时必须先确认走哪条**：

| | 路径 A · 动作迁移（默认） | 路径 B · 提示词反推（三视图直采） |
|---|---|---|
| 原理 | 参考图给外观 + 源舞视频给动作轨迹，应用做动作迁移 | 抽帧看懂舞蹈 → 写 H3 Ref2VA 提示词；三视图+场景图直接进 t8balance |
| 动作还原 | **高**（动作直接迁移源舞，队形/节拍几乎一致） | 中高（靠提示词描述，复杂动作/多人队形可能偏差，需抽帧核验） |
| 是否生成真人参考图 | 要（65535 图生图，全身正面硬要求） | **不要**（原始三视图 PNG + 场景图直挂，省一道工序与费用） |
| 多角色 | 每次 1 张参考图，群舞要多次出片再拼接 | 一次最多 9 张参考图（node 6/35–42），多角色可同框共舞 |
| 场景 | 画进 65535 参考图 | 场景图独立占一个 Picture 槽 |
| RunningHub 应用 | `1975951975441412098`（plus） | t8balance `2095868555916038145`（plus/ultra，≤10s 稳定） |
| 成片检查 | 不抽帧，直接交付 | **必须抽帧核验**（身份/舞句/场景/无 UI） |
| 成本/耗时 | plus 15s/720P ≈ 884 币、约 37 分钟 | 10s 实测 298 币、约 12 分钟 |
| 适合 | 动作还原优先、单/双角色、长舞 | 探索画质、多人群舞、想省去参考图生成 |

选择规则：

- **用户主动点名即用其选择**：「动作迁移/迁移那个舞」→ A；「反推提示词」「t8balance」「三视图直采」「直接用三视图和场景图」「不走动作迁移」→ B。
- **用户没点名时，先问一句再开工**（用 AskUserQuestion 或自然语言二选一）：「这次舞蹈复刻走哪条路径？A 动作迁移（动作最还原，要先生成真人参考图）／B 提示词反推三视图直采（省一步、可多人同框，动作靠提示词）」。
- **goal 模式（无人值守）下用户什么都没说 → 默认走路径 A 动作迁移**，不要停下来等选择，也不要默认 B。
- 已有成片说「发布/同步到 B站/抖音」→ 与路径无关，直接走 Step 5。

选定后的流程：

- **路径 A**：解析指令（角色+造型+场景+舞蹈）→ 扫 `dances\` 选舞 → 定位三视图 → 65535 生成全身正面真人参考图（归档 `<项目>images\`）→ 应用 `1975951975441412098` 动作迁移 →（可选 BGM）→ 发布（下文 Step A1–A4 + 共享 Step 5/6）。
- **路径 B**：解析指令 → 扫 `dances\` 选舞 → 抽帧反推动作写节拍表与 H3 提示词 → 定位三视图+场景图 → t8balance 多参考直采出片 → **抽帧核验**（不合格改提示词重跑）→（可选 BGM）→ 发布（下文 Step B1–B5 + 共享 Step 5/6；提示词写法规范见 `references\ref2va-dance-prompt-guide.md`）。
