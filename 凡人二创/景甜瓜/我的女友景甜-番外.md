# 《我的女友景甜》番外 · 五千万灵石（MiniMax H3 15秒）

> 时间线插于第2集（三千万聘礼）与第3集（六千字玉简）之间，补完决裂起因。
> 素材对应：孙宇晨长文披露——景甜赴美代孕，洛杉矶诊所取卵前索要5000万美元；他没有直接回应，用 Claude Code 把现金资产全面跑了一遍，犹豫之后没有答应。

生成一段15秒、16:9、2K、原生立体声的写实仙侠动画短片，《我的女友景甜》系列番外·五千万灵石：慕沛灵在乱星海琉璃仙城化灵阁取灵卵前夜，向韩立开口索要五千万灵石才愿继续；韩立沉默以对，驱动木傀儡将全部身家盘点了一遍，指尖悬在储物袋上迟迟未解，最终没有点头应允，一段姻缘自此生出无声裂痕。

人物锁定：韩立为二十余岁青年修士，面容清瘦沉静，黑发束以金簪，一袭深青蓝广袖长袍、金色腰封垂红穗蓝绦流苏；慕沛灵为绝色温婉的红衣女子，红色V领锦缎罗裙配金色腰封流苏挂饰、双髻簪金饰；木傀儡为铜关节木质机关人偶，执册静立案边；三者的面容、发型与服装与本系列各集完全一致。

0—3.5秒：琉璃仙城化灵阁静室，深夜。室心悬一面白玉灵鼎，鼎身流转温润白光，鼎内一线青碧灵光如茧静静吐纳。中近景：慕沛灵立于鼎前缓缓转身，面向房中另一端的韩立，对白为中文，口型完全同步，声音清冷平静、不疾不徐："五千万灵石。给我，我便继续。"

3.5—6.5秒：韩立沉默两拍，眉目沉静依旧，抬手掐诀。案边木傀儡铜关节轻响启动，展开一卷账册与储物袋清单，灵光数字在册页上飞快流转，盘点声如算珠轻响。

6.5—9.5秒：特写账册：盘点数字汇成"全部身家"一行总额，与朱笔写就的"五千万"数目并排而列。镜头缓推至韩立手部：他指尖悬在储物袋系带之上，悬停一瞬、收回半寸、再度悬住，最终没有解开系带。

9.5—12秒：慕沛灵的目光落在他垂下的手上，睫毛极轻地颤了一瞬，唇边笑意淡去。两人隔室对视，静室中只余灵鼎嗡鸣与远处海风。

12—15秒：韩立袖手垂下，低声开口，对白为中文，口型完全同步，声线低哑克制："……再容我想想。"慕沛灵闻言侧身望向鼎心青光，不再看他；韩立袖中半枚玉佩的灵光极轻地一黯。同一轮月透过窗棂照入，两人一鼎一案分立画面两端，定格于无声拉开的距离。

剪辑与表演规则：切点分别落在慕沛灵台词收束、木傀儡启动、账册特写推近、指尖收回、对视静默与袖手垂下；韩立的表演信号仅保留沉默两拍、指尖悬停收回与袖手垂下三处，前后连续；慕沛灵的表演信号为转身、睫毛轻颤与侧身望鼎，呼应第二集埋下的伏笔；木傀儡盘点动作完整连贯，铜关节每次轻响对应一次切镜或推镜。

视觉风格与材质：写实仙侠CG动画，冷青月夜为主色调，白玉灵鼎的温润白光与鼎内青碧灵光形成柔和对撞，烛火暖金点缀案角；琉璃殿壁通透如冰、映出月色；红罗裙绸缎与深青蓝长袍织锦质感清晰，账册玉简与储物袋皮革纹理分明，木傀儡木纹与铜关节肌理细腻，夜雾颗粒感轻盈。

声音设计：原生立体声——灵鼎低回嗡鸣贯穿全片作为声音桥、木傀儡铜关节轻响与册页翻动、灵光盘点数字的细碎算珠脆响、玉佩灵光一黯的极轻钝响、海风拂过琉璃殿檐的猎猎轻鸣；两段对白贴近收音、气声清晰；配乐以古琴散音与一支孤箫为主，在玉佩钝响处收束。

全片十五秒无缺口，白玉灵鼎、账册与半枚玉佩贯穿本集，结尾以两人隔月对望的定格，完成从谈婚论嫁到裂痕初现的关系转折，为第三集六千字玉简的引爆埋下无声引线。
