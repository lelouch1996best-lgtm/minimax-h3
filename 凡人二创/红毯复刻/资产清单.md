## 与 H3 视频提示词的关联

每段一份提示词、一张参考图，提交 H3 生成时按以下方式引用：

```
段1：@图片1作为南宫婉身份与服装参考（E:\短剧平台\凡人二创\人物图\南宫婉\图片.png）

段3：@图片1作为紫灵身份与服装参考（E:\短剧平台\凡人二创\人物图\紫灵\紫灵.png）
段4：@图片1作为幕沛灵身份与服装参考（E:\短剧平台\凡人二创\人物图\幕沛灵\人物三视图（基础）.png）
```

参考图在提示词中锁定面容与发型，红毯礼服（深红丝绒鱼尾裙 / 玄黑丝绒高开衩鱼尾裙 / 黑丝绒紫蝴蝶结长裙 / 酒红大摆露背礼服）由各段人物锁定段落描述，不要求与参考图服装一致。
