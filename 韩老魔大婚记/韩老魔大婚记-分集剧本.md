## 二、跨集一致性锚点

### 1. 服装锚点
- **韩立·玄色喜袍**：黑发束簪 + 玄色喜袍（黑丝绸底，红金绣龙纹）+ 金色肩饰 + 红色腰封 + 黑色婚靴。E01–E05全程一致，E06化光时金饰碎散。
- **南宫婉·凤冠霞帔**：金色凤冠（红金双色，珍珠串坠垂挂）+ 红色嫁衣霞帔（金凤绣纹）+ 红盖头（遮上半脸）+ 额间金色火焰纹花钿 + 珍珠耳环。E01–E05盖头固定，E06揭盖。

### 2. 遁光递进锚点
| 集数 | 遁光 | 角色 | 情绪色彩 |
|------|------|------|----------|
| E02结尾 | 淡青色遁光 | 穆沛灵 | 委屈急切 |
| E03开头 | 紫色遁光 | 紫灵 | 沉稳压迫 |
| E04开头 | 无遁光（冲出） | 梅凝 | 崩溃哭诉 |
| E05开头 | 金色遁光 | 王蝉 | 怒意质问 |
| E06开头 | 翠绿色遁光 | 韩立 | 决绝逃离 |

### 3. 场景锚点
- **白玉广场**：悬浮于灵云之上，四角通天玉柱刻上古符文灵光明灭，周围数十座悬浮石台错落分布。E01全景建立，E01–E06无缝衔接。
- **玉砖裂纹**：E04 12-13秒南宫婉灵压骤重使玉砖出现蛛网细纹，E05继续蔓延，E06停止蔓延。裂纹是"新娘怒意"的可视化时间线。

### 4. 红盖头锚点
- E01：盖头遮面，只露光洁下颌
- E02：盖头纹丝不动，灵力波动微收
- E03：盖头不动，灵压收紧如空气变沉
- E04：盖头不动，灵压加重玉砖开裂
- E05：指尖触盖头边缘，所有人屏息
- E06：盖头缓缓揭起，露出完整面容

### 5. 连环钩子链
```
E01 "等一等——！" ──→ E02 穆沛灵跪地求妾 ──→ 紫色遁光
  ──→ E03 紫灵问前世 ──→ "韩立——！！"
  ──→ E04 梅凝哭诉初吻 ──→ 男声怒吼"韩立——！！"

  ──→ E06 韩立化绿光遁走，全剧终
```

## 七、使用说明

1. **Ref2VA 投喂顺序**：按 @图片1–7 的编号依次上传对应角色三视图至 H3 Ref2VA 的参考图槽位。
2. **逐集生成**：将各集 .md 文件中的完整 prompt 复制至 H3 文戏模式输入框，确保 @图片N 引用行在最顶部。
3. **跨集校验**：每集生成后，检查"一致性收束"段落中列出的锚点是否在画面中完整呈现。
4. **剪辑拼接**：6集按 E01→E02→E03→E04→E05→E06 顺序拼接，集间无需过渡，各集结尾与下集开头在时间线上无缝衔接。
