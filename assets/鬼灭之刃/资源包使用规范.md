## 2. 采集与核验流程（重要，血泪史）

本包全部参考图均经 **"下载 → 拼联系表 → 逐张肉眼核验"** 三步。**不要跳过核验**，实测有以下三类坑：

| 坑 | 实例 | 处置 |
|---|---|---|
| **图与角色不符（串图）** | Tavily 抓到的 `asia.sega.com` 图可能是该站其他页面的 og:image | 逐张看图确认 |
| **官方页数字编号无 alt** | 动画官网「無限列車編」用 `img_cha_01.jpg` / `thumb_02.png`，**实测与角色完全不对应**（炼狱名下拿到的是炭治郎、祢豆子） | **禁用该篇章页按编号取图**；炼狱改用 SEGA |
| **非原作造型混入** | SEGA「火之神血风谭2」含大量**鬼灭学园版**（宇髄天元＝美术教师扛画笔、炼狱＝白衬衫红领带） | 一律移入 `_废弃_非原作造型\` |

- **可行来源排序**（2026-10-07 实测存活率）：
  1. **动画官网 kimetsu.com**（`/anime/{篇章}/character/`）— 官方立绘，最稳，画风统一；
  2. **SEGA 官方游戏站**（`asia.sega.com/kimetsu_hinokami*/…/character/chara{N}.png`）— 全身动作立绘；
  3. **百度百科 `bkimg.cdn.bcebos.com`** / **萌娘百科 `storage.moegirl.org.cn`** / **bilibili wiki `patchwiki.biligame.com`** — 图片 CDN 可用；
  4. **SEGA 2 代角色表**：`https://asia.sega.com/kimetsu_hinokami2/cht/character/characterlist.json`（含 num ↔ 角色名映射，图片路径 `…/assets/img/character/main/chara{num}.png`）。
- **已知不可用**：`static.wikia.nocookie.net`（403 防盗链）、`upload.wikimedia.org`（网络不通）、`i.pinimg.com`（超时）、`i.imgur.com`（失败）、萌娘百科**页面**（403，仅图片 CDN 可直取）。
- **复采脚本**（都在 `tools\`，可复用）：
  ```
  gm_tavily_refs.py      # Tavily 逐角色搜图（include_images）
  gm_download_refs.py    # 下载 + 存活校验 + 清单
  gm_sega_dl.py          # SEGA 1 代立绘（/cht/ 路径）
  gm_official_refs.py    # 动画官网全篇章立绘
  gm_contact_sheet.py    # 拼联系表（OpenCV，中文路径走 imdecode/imencode）
  gm_tidy_refs.py        # 归档非原作/错配/重复项（dry-run 默认，加 --write 执行）
  ```
  抽帧/拼版类脚本必须用 venv：`C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Scripts\python.exe`（managed 版无 cv2）。

## 4. 造型避坑（硬性）

- **不采用「鬼灭学园」造型**（`_废弃_非原作造型\`）：与正片造型差异极大。
- **不采用手办/周边实拍**作身份基准（`_废弃_周边实拍\`、`_备选_服装实拍\` 仅供服道化质感参考）。
- **含大量文字/水印的画面**（单行本封面、联动海报、设定稿标注）只作造型参考，**不作图生图底图**（`_备选_带文字海报\`）。
- **漫画/插画风**（萌娘百科部分图）若与目标真人质感冲突，不作为底图，仅作造型比对。
- **角色双状态注意**：我妻善逸「醒／睡」、祢豆子「人形／鬼化」、炭治郎「水之呼吸／火之神神乐（赫刀）」——提示词必须显式指定其一，禁止默认混用。

## 5. 三视图生成（本包既定路线）

**路线：先搜官方图（已完成）→ 以官方图为参考做图生图 → 得真人质感三视图。**

- 工具：**65535 图生图**（`gpt-image-2`）。**`gemini-3-pro-image` 已禁用**（生成人物与参考图不像）。
- **三视图必须走「三视图生成前确认」**：提交前先向用户展示①修改点（逐角色造型设计）②画风（参考图选哪张、画风锁定方式、排版）——得到明确同意后再提交。
- 排版固定提示词（开头）：
  ```
  完整角色设定稿，白色背景，同画布分左右两列排版：第一列超精细面部特写（占30%宽度），第二列角色标准三视图（正面 / 侧面 / 背面）（占70%宽度）。画面中不出现任何文字、字母、数字、标注或水印（包括「正面 / 侧面 / 背面」等视角标签与角色名）。
  ```
- **画风基准与身份锁定**：从 `character\_人物资产索引.md` 各角色「首选底图」取参考图；身份锁定用**引用式写法**——
  「严格保持参考图中同一人物的面部五官、脸型、发型发饰与服装形制不变（以参考图为唯一身份基准，不换人、不改发型与服装形制）」
- **真人质感**：完整基准见 `assets\真人质感美术基准.md`（拼装顺序：构图排版 → 身份锁定 → 真人质感 → 剧本场景 → 反向约束，反向约束须逐条照抄）。
- **成本参考**：65535 / gpt-image-2 / 9:16 / 2k / n=1 ≈ $0.038 单图、70 秒内完成。
- **批禁止抽卡**：同一需求"不满意就再摇一版挑一张"须先取得用户同意（说明摇几次、预估费用、落选图处理）。

## 6. 索引同步

角色参考图增删后，**先更新 `character\_人物资产索引.md` 再动笔写提示词**，避免索引与目录脱节。本包不套用凡人包的 `tools\sync_character_index.py`（该脚本按凡人命名 `人物三视图（{造型}）` 解析，与本包 `官方参考\` 阶段不匹配）；改用：
```
python tools\gm_contact_sheet.py     # 重出联系表（顺带列出每角色当前图数）
python tools\gm_tidy_refs.py         # 预览归档差异
```
