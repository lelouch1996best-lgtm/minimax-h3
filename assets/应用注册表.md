# 应用与工作流注册表

**用途**：RunningHub API 无法查询"我的收藏/我的应用"——`--list` 返回的是应用市场全量推荐列表（7 万+ 条），不含个人收藏。本表作为**本地收藏夹**，供 h3-drama-producer Step 6 选择提交方式时展示给用户。

**登记规则**：

- 新应用（appId）/ 新工作流（workflowId）**首次调用成功后**，立即登记到对应表格
- 登记字段：名称、ID、用途、备注（instanceType 要求、价格实测等）
- 节点信息**不做文档缓存**：任何 appId/workflowId 用 `--info` 动态查询（nodeId、fieldName、description、当前值、可选值枚举），永远与线上版本同步
- 弃用条目标注"已弃用"，不删除（保留历史）
