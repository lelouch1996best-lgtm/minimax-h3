## 2. 采集与核验流程（重要）

本包全部参考图均经 **"下载 → 拼联系表 → 逐张肉眼核验"** 三步。**不要跳过核验**，实测有以下三类坑：

| 坑 | 实例 | 处置 |
|---|---|---|
| **官网防盗链** | `one-piece.com` 直接请求返回 **403 Forbidden** | 请求头必须带 `Referer: https://one-piece.com/character/{slug}/index.html`，实测即可 200 |
| **官网画廊图实为动画截图** | `官网({slug})-02..09.jpg` 是带背景的剧集截图，非干净立绘 | 仅作造型比对；**不作干净身份底图**，作参考时必须写明"不要沿用背景" |
| **补搜图混入非原作美术** | Tavily 直出图含**手办/雕像实拍**、**带「ONE PIECE」大字海报** | 逐张看图确认，移入 `_废弃_周边实拍\` / `_备选_带文字海报\` |

- **可行来源**（2026-10-07 实测）：
  1. **one-piece.com 官方角色页**（`/character/{slug}/index.html`）— `og:image` 给出 `/o/assets/images/anime/character/data/{slug}/face.jpg`（干净头像）；页面内 `/img/character/{slug}/{slug}_NN.jpg`（NN=02..09，动画截图）。**必须带 Referer**。
  2. **Tavily 图搜**（`include_images`）— 可拿到白底全身立绘，但需人工筛除手办/海报。
- **复采脚本**：`tools\op_probe_official.py`（探测官网结构）／`op_official_refs.py`（官网采集思路）／`op_tavily_refs.py`（Tavily 搜图）／`op_download_refs.py`（下载+校验+清单）。
- 抽帧/拼版类脚本必须用 venv：`C:\Users\Administrator\.workbuddy\binaries\python\envs\default\Scripts\python.exe`（managed 版无 cv2）。

## 4. 造型避坑（硬性）

- **不采用手办/雕像实拍**作身份基准（`_废弃_周边实拍\`）。
- **含大量文字/logo 的画面**（单行本封面、联动海报）只作造型参考，**不作图生图底图**（`_备选_带文字海报\`）。
- **动画截图（带背景）不作干净底图**：`官网({slug})-02..09` 一律须在提示词中排除背景。
- **角色形态/时期注意**：索隆「两年后」左眼闭合、山治「两年后」露卷眉、乔巴为驯鹿人形态、布鲁克为骷髅、甚平为鱼人——提示词必须显式指定，禁止默认混用。

## 5. 三视图生成（本包最终路线）

**路线：先搜官方图（已完成）→ 以官方图为参考做图生图 → 得三视图。**
**最终采用：65535 站 `gpt-image-2` 图生图（16:9 / 2k），与鬼灭之刃包同一条产线。**

> 曾试过 `byted-ark-seedream-skill`（火山方舟 AgentPlan · Seedream 5.0），已废弃，原因见本节末尾「两条路线的取舍」。

- **驱动脚本**：`tools\op_gen_views_gpt.py`。用法：
  ```
  # Key 取用户级环境变量 S65535_API_KEY
  python tools\op_gen_views_gpt.py --only 蒙奇D路飞    # 单角色试跑
  python tools\op_gen_views_gpt.py                    # 全部 10 人
  ```
- **三视图必须走「生成前确认」**：提交前先向用户展示①修改点（逐角色造型设计）②画风（参考图选哪张、画风锁定方式、排版）——得到明确同意后再提交。
- **参考图传入顺序**（固定）：**第 1 张 = 画风基准**（凡人包 `assets\凡人\character\韩立\人物三视图（基础）.png`：真人质感 3D 渲染 + 白底两列版式），**第 2 张起 = 身份来源**（逐角色定制的官方立绘 / 面部特写）。
- **排版固定提示词**（开头）：
  ```
  完整角色设定稿，白色背景，同画布分左右两列排版：第一列超精细面部特写（占30%宽度），第二列角色标准三视图（正面 / 侧面 / 背面）（占70%宽度）。画面中不出现任何文字、字母、数字、标注或水印（包括「正面 / 侧面 / 背面」等视角标签与角色名）。
  ```
- **身份锁定**：每张身份参考图后紧跟一句用途说明（「只取面部五官与服装形制，不要沿用背景与动作」），再给角色造型描述；**非人形角色（乔巴 / 布鲁克 / 甚平 / 弗兰奇）必须显式声明形态**，否则会被画成普通人类。
- **真人质感**：完整基准见 `assets\真人质感美术基准.md`（拼装顺序：构图排版 → 画风基准说明 → 身份锁定 → 角色描述 → 真人质感 → 反向约束，反向约束须逐条照抄）。
- **批禁止抽卡**：同一需求"不满意就再摇一版挑一张"须先取得用户同意（说明摇几次、预估费用、落选图处理）。
- **本次实测踩坑（重要）**：
  1. **参考图必须走本地 base64 上传**（脚本 `load_b64` 把本地图缩到长边 1536、JPEG q86 后编码）。**不要传公网 URL**——`gamersky` 等 CDN 对服务端抓取返回 **403**，会直接导致任务失败（Seedream 路线实测踩到，`妮可罗宾` / `甚平` 因此失败）。
  2. **暴露度高的立绘会触发 OpenAI 安全审核**：`娜美` 的官方全身立绘连续两次被拒（`upstream_error`：`请求被OpenAi审核拒绝`）。解法是**改用官方面部特写作身份参考、服装由文字描述**，即可通过。
  3. 单张出图约 1 分钟，10 人批量约 5 分钟；建议后台运行。
