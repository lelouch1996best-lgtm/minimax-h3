## 1. 心态（Basic mindset）

- 像一张自然的生活照：照片里是一位明确的成年女性（默认二十多岁；为过上游审核提高年龄锚点时的措辞见各技能 SKILL.md），真实到可以出现在真实的社交平台信息流里。
- 压制 CG 质感、强美颜滤镜、塑料皮肤与不自然的高光。
- 保留吸引力，但不要把脸和皮肤做成不可能的完美。
- 避开时尚大片 / 广告造型，走日常摄影。
- 真实存在感、被生活使用过的细节、自然的不完美，优先于完美。

## 2. 摄影与质感（Photography and texture）

- 用手机随手拍的观感，不用高端相机的大片感。
- 用自然窗光，或场景里本来就有的实用光源（大殿里即窗光 / 烛火 / 灯盏；闺房里即烛光 / 窗光 / 室内暖灯）。
- 允许轻微手持抖动带来的柔焦、手机传感器噪点、轻微锐化痕迹、略粗糙的分辨率。
- 构图允许略有瑕疵：轻微倾斜、留白不均、轻微裁切、偏离中心。
- 不要摆拍姿势，要"被随手拍到的瞬间"。
- 不要滥用电影级浅景深——普通手机反而让场景更可读。

## 3. 面部细节（Facial details）

- 真实的面部比例与骨相。
- 不放大眼睛；保留真实巩膜比例、眼睑厚度、左右细微差异。
- 表情克制、自发；浅笑或放松的中性表情优于刻意咧嘴笑。
- 除明确要求外，避免正对镜头的证件照式构图。
- 保留眉、眼、脸颊、嘴部轻微的不对称。

## 4. 收尾细节（Final touches）

- 保留毛孔、细小绒毛、柔和泛红、微小瑕疵与自然的阴影变化。
- 手与手指的数量、关节、长度、交叠、握持都要合理。
- 整体干净、亲和、可爱，同时在物理上可信。
- 头发要有飞散碎发、不均匀发束、轻微毛躁，而非根根分明的发丝。
- 身体比例与参考或需求一致，避免夸张沙漏型与模特级修图。
- 要"现实中可能存在的可爱"，不要娃娃般的完美。

## 5. 常用反向约束（Common negative constraints）

**通用反向约束清单（两系列逐条照抄、不得精简）：**

```
避免：CGI、3D 渲染、娃娃皮肤、瓷肌、过度磨皮、美颜 App 瘦脸大眼、眼睛过大、面部完全对称、
睫毛过度锐化、油蜡感高光、影棚打光、商业时尚大片、刻意轮廓光、极端背景虚化、过度 HDR、
毛孔纹理过度锐化、不真实的解剖比例；
画面无任何文字、字幕、水印、logo，无第二个人物，无现代物品穿帮；
手与手指的数量、关节、长度、交叠与握持合理（无多指、无粘连）；
首饰不重复不悬空、不穿模，背景陈设不变形不重复。
```

**profile 附加反向约束：**

| profile | 附加条目 |
|---|---|
| `portrait`（近景） | 无（近景不裁脚是常态，不加反而干扰构图） |
| `fullbody`（全身） | `全身完整：不裁切头部、不裁切脚部、不出现半身或只有上半身的构图；`<br>`朝向正面：不侧身、不背对镜头、不回眸侧脸、不低头遮脸、不出现背面或侧面视角；`（2026-09-20 用户指定：动作迁移需要人物正面） |

### 7.2 与固定画幅约束的优先级

以下硬约束**优先于**基准里"更随意的构图"：

1. 画面只保留一个人物（不得出现三视图拼贴、多视图、白底排版）
2. **`portrait`**：面部完整清晰（轻微倾斜、偏离中心可以，但不能挡脸或裁掉五官）
   **`fullbody`**：全身完整入画，不裁切头部、不裁切脚部，不出现半身或只有上半身；且**人物正面朝向镜头（正脸正身）**，不侧身、不背身、不回眸
3. 场景必须与指令一致（单场景、无现代物品穿帮）

其余生活感、反美颜、不完美细节等基准条目一律照写。
