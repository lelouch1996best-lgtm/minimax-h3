## 2. 三视图定位与命名

- 标准路径：`d:\work\minimax_h3\assets\凡人\character\{角色}\人物三视图（{造型}）.png`
- **目录名容错**：用户常把「幕沛灵」写成「穆沛灵」（穆=幕），**以资产库实际目录名为准**（实际为「幕沛灵」）；拿不准先 LS 该角色目录，不臆造路径。
- **非标准命名也真实存在**（以 LS 结果为准，别照标准式硬拼）：
  - 元瑶基础造型为 `人物人视图（基础）.png`（"人视图"非"三视图"），另有 `人物人视图（宫装）`、`人物人视图（劲装）`、`人物人视图（泳装）`
  - 李缨宁另有 `人类质感.jpg`（真实肤质参考）、`特写图.jpg`
  - 部分角色只有 `特写.png`（无「图」字），如凌玉灵、梅凝
  - 韩立另有道具/形态图 `风雷翅.png`，银月另有 `银月兽形态.png`，均非三视图、不作身份基准
- **真人质感造型文件名不统一（2026-10-11 收录）**：王蝉为 `真人质感_皮夹克`、`真人质感_保安制服`（**下划线**），南宫婉为 `西装-真人质感`（**语序与常规「真人质感-XX」相反**），《每月十五号》文档里又写作「真人质感-皮夹克」「真人质感-职业西装」——引用前一律 LS 该角色目录，以实际文件名为准。
- **voice 目录命名容错**：音色文件实际为「南宫婉、**南宫阙**、李缨宁、**穆沛灵**、银月、韩立」6 个 —— 幕沛灵目录下的音色写作**穆沛灵.mp3**（同音别字），且南宫阙为独立音色（非南宫婉笔误），引用前先 LS `voice\` 核对。
- **同一角色有多套造型**时按剧情/场景气质选用；同一角色有多张三视图且用途不明时，先向用户确认选哪张。

## 3. 造型避坑（硬性）

- **不要**选带明显漫画/二次元底子的造型当底图：`人物三视图（昭和·漫画风）`（实际文件名为 `基础·昭和漫画风`）、`人物三视图（校服）` 一律排除。
- `昭和` 造型可选，但**只接受真人/古风质感的昭和**；拿不准先看该造型三视图确认画风。另有 `昭和2D`（南宫婉/幕沛灵/韩立）从命名看即 2D 画风，按漫画风同等处理、默认排除。
- **现代/特殊造型默认不进古装正片**：`球队`、`打工围裙`、`皮夹克`、`童装`（火龙童子）、`老版本`（南宫婉）、`夜色`/`白礼服`（李缨宁）、`西装-真人质感`（南宫婉）、`真人质感_皮夹克`/`真人质感_保安制服`（王蝉）等按剧本需要单独确认，不混入古风镜头。
- 优先真人/古风质感造型：宫装、敦煌、基础古风，以及 `人类质感.jpg` 这类真实肤质参考。
- **银月**为狐耳非人类设定，慎选（除非剧本明确要兽耳）。

## 5. 身份锁定写法

- 优先从 `_人物资产索引.md` 复制该角色外观锚点（五官/发型/服装），填入提示词身份锁定段。
- 索引标「以图片为准」且**无多模态读图能力**（Read 图片报错）时，改用**引用式写法**（不罗列特征）：
  「严格保持参考图中同一女性的面部五官、脸型、发型发饰与服装形制不变（以参考图为唯一身份基准，不换人、不改发型与服装形制）」

## 7. 索引自动同步

角色三视图增删后，先跑同步脚本再动笔写提示词，避免索引与目录脱节：

```powershell
python tools\sync_character_index.py            # 预览（dry-run），只报差异不写文件
python tools\sync_character_index.py --write    # 确认后把新角色/新形象写回索引
```

- 自动识别标准命名 `人物三视图（{造型}）` 与变体 `人物人视图（{造型}）`，新条目一律按「以图片为准」登记。
- 非标准命名（特写图 / 详细信息图 / 人类质感 / 风雷翅 / 兽形态等）**不自动登记**，仅在报告里列出，人工判断。
- 新角色性别为启发式推断，`--write` 后须人工核对并补正文外观锚点。
