# 恶搞素材包（EG · Parody / Creature）

**创建日期**：2026-10-08
**定位**：恶搞、整活向**原创角色**包。角色没有原著 IP 背书，也不走「先搜官方参考图再图生图」的路线。

## 与其他素材包的根本差异

| 项 | 凡人 / 海贼王 / 鬼灭之刃 | 恶搞（本包） |
| --- | --- | --- |
| 形象来源 | 原著官方立绘 → 图生图锁身份 | **纯文字提示词原创设定**，无身份参考 |
| 参考图作用 | 官方立绘锁身份 + 角色自身三视图锁身份 | **只传凡人包韩立真人质感三视图作「版式 + 写实画风」基准** |
| 是否需搜官方图 | 必须（硬规则一） | 不需要（本就不存在 IP） |
| 配方 | 单参考图优先 | 单参考图（画风源） |

**关键提醒**：唯一参考图只用于「左列特写 + 右列正/侧/背三视图」两列版式、纯白摄影棚背景、写实电影级生物渲染质感与柔和布光。**提示词里必须显式写明「不要沿用参考图的人脸/发型/服装/古装元素」** —— 否则模型会把韩立的长袍和脸带进来。

## 🔴 低分辨率「神态参考图」的处理法（猴头踩出来的）

用户提供了一张 76×75 px 的真人脸小图，只要求「五官稍微参考」。

**正确做法：不做图生图输入，只把观察到的五官特征逐条文字锁进提示词。**

| 步骤 | 做法 |
| --- | --- |
| 1 | 先把原图放大 8× 存盘，**Read 读放大图**逐条描述五官（脸型/眼型/眼皮/眼距/鼻/唇/表情），不要凭印象写 |
| 2 | 参考图槽仍只传「画风源」（凡人包韩立真人质感三视图），保持单参考图配方 |
| 3 | 五官特征写成一个独立段落 `FACE`，**写死五个维度**：脸型 / 眼睛（大小+眼皮+眼型+眼距+瞳色）/ 眉毛 / 鼻子（鼻梁+鼻头+鼻翼+鼻孔朝向）/ 嘴唇（上下唇比例+唇线+嘴角）+ 表情（露出哪几排牙、门齿、笑纹） |
| 4 | 负面清单加一条 **「避免真实人类面孔、不要照片里的人脸、五官必须明确是XX脸而非人脸」** —— 文字描述五官时模型很容易滑回真人脸 |
| 5 | 出图后 2.5× 裁放脸部与手部逐块肉眼核验 |

**为什么不直接传**：① 分辨率太低，模型会把糊像素当纹理；② 会引入真人肖像，生成出来是「穿西装的照片男」而不是妖怪；③ 单参考图配方（见下）已实测更稳。

## 形态图生成配方（法天象地这类「角色放大/异形态」场景）

**脚本以线条虚影版为准**：`tools/eg_gen_dazuoyu_fatxd_v2_lines.py`
（v1 `eg_gen_dazuoyu_fatiangxiangdi.py` 实体画法已弃用，保留仅供对照）

这类**不是三视图**，不用两列版式，改为**双参考图**：

| 参考图 | 作用 | 提示词里怎么写 |
| --- | --- | --- |
| 角色三视图 | 唯一身份基准 | 「把第 1 张图里的角色整体**替换成线条虚影**后再叠进场景」+ 逐条列鱼头/西装特征 |
| 氛围参考图 | 画风 + **人物形态** + 构图 + 配色 全基准 | 「严格照搬图里人物的画法，一比一复现那种材质」+ 逐条列要借的东西 |

- 输出 16:9 / 2k / 2048×1152 横幅
- **🔴「虚影」必须写成独立段落（`FIGURE_FORM`），不能只当形容词塞进质感段。** 教训：v1 把法相写成了「实体法相」（用了「次表面散射、鳞片厚度、实体布料褶皱」这些词），模型照做画出了有厚度的实体人，完全不是参考图那种半透明光影。v2 改法：
  1. 独立段落第一句就写死「**不是实体，而是一道完全由光线与线条构成的超自然虚影**」
  2. 逐条拆解虚影的 5 个特征：半透明可透视 / 极细流线一根根勾（非均匀描边）/ 外缘虚化消散成光点 / 光柱贯体亮度递减 / 有 bloom 与半透明叠加
  3. 西装在虚影里也要「以发光线条网格呈现（驳头线、纽扣、排扣线都要勾出来）」
  4. **负面清单置顶加一条排除实体**：不透明实体、真实皮肤血肉、肌肉块面、暗部黑块、实体布料褶皱阴影
- 负面清单另需两类：**①** 排除氛围图里的人物外形（长发/尖耳/仙袍/美男子脸/悬浮仙岛）；**②** 禁改服装（`禁止铠甲/长袍/披风/僧袍`），否则「西装妖怪」会被仙侠题材同化成古装
- **核验重点是手部**：法相巨大时手常畸变，必须裁放 2× 数指头；裁前先目视定位，坐标估错会裁到云（本次裁歪一次）
- **用户反馈优先于我的美术判断**：用户说「人物应该是虚的、由线条构成」→ 直接重写，不要试图解释实体版好在哪


## 三视图生成配方（复用方法）

脚本：`tools/eg_gen_dazuoyu_views.py`（单角色版）。要新增角色，复制该脚本改 `CORE` / `VARIANTS` 即可。

- API：`https://task-api-1-cn.65535.space`，model `gpt-image-2`（**2026-10-08 起默认模型已更新为 `gpt-image-2.5-flare`**，脚本里仍写 `gpt-image-2` 的需改），`size=16:9`、`resolution=2k`、`n=1`
- 画风参考图：`assets/凡人/character/韩立/人物三视图（真人质感-基础）.png`（长边压到 1536，JPEG q86，base64 data URI）
- 提示词拼装顺序：`版式 → 画风锁定（含「勿沿用参考图人物元素」）→ 形象核心+服装 → 写实质感 → 场景 → 负面清单`
- 变体策略：一次提交 2 个服装变体（A/B），人工肉眼核验后选主档
- 单次实际耗时约 35 秒出图

**写实生物质感要点**（区别于真人角色）：不要写「真实亚洲女性皮肤」，改写「次表面散射 + 湿润黏液反光 + 鳞片边缘翘起 + 眼球充血湿润」；同时必须压制「卡通 / 动漫 / 玩具 / 搪胶手办 / 廉价 CG」，并在负面清单里显式加「恐怖 / 血腥 / 狰狞」防止形象滑向怪物片。

## 剧情场景图配方（多主体同框 · 第五集踩出来的）

**脚本**：`tools/eg_gen_ep5_stomp_keyframe.py`（三变体 A/B/C，一次提交约 2.5 分钟）

场景里同时出现**主体 + 次要主体**时（如「一只大脚踹碎法相」：鞋+标识是主体，相是次要），仍用双参考图，但分工要对调：

| 参考图 | 作用 | 提示词里怎么写 |
| --- | --- | --- |
| 角色形态图（线条虚影） | **次要主体**的身份 + 材质 | 放在段落靠后，长度**压缩到不超过主体段** |
| 道具图（`props/大脚标识.png`） | **主体**的唯一形态基准 | 放最前，写足四件事 |

- 提示词顺序：**主体道具 → 标识 → 基调 → 次要主体身份 → 材质 → 构图 → 场景 → 质感 → 负面清单**
- 输出 9:16 / 2k / 1152×2048 竖幅（与本系列竖屏成片一致）

### 🔴 教训：主角会挤掉次要主体的身份描述

**现象**：三张成图里鞋与标识都完美，但**虚影的西装驳头线、双排扣纽扣线全部消失，鱼头的巨嘴轮廓与呆滞傻笑也糊了**，人形糊成一团光丝。

**根因**：提示词里虚影的材质段（`FIGURE_FORM`）写得最长最长，模型把它当成全图主描述来执行；身份锁定段虽存在但字数与位置都不占优，被灵气材质挤掉。**「写了」不等于「模型会画」—— 主次冲突时长段落会输。**

**对策**（本次未采纳，留档备用）：把身份锁定提到提示词最前、用「先画 X，再画 Y，最后画 Z」显式排序、压缩材质段篇幅。

**用户裁决**：「算了，就用现有的」——喜剧向分镜里观众看的是被踹飞的动作，不强求认西装细节。**但若后续要做成片/需要角色辨识度，就必须按上面的对策重出。**

### 标识类道具的写法（写足四件事 + 声明非文字）

`props/大脚标识.png` 是**纯几何图形徽标**，不是汉字/字母。实测有效写法：

1. **形态**：底色 `#F4CB4F` 暖黄方徽 + 「一条横向黑色粗弧带（弧顶朝上）+ 两端各向下弯垂收笔成两条短粗垂脚」，并强调「除这一个符号外不得有其他图形」
2. **声明非文字**：「这个符号是纯几何图形徽标，**绝对不能**被画成汉字、英文字母、阿拉伯数字、拼音」
3. **位置**：鞋底正中偏后（鞋跟与鞋掌中线），随鞋底透视压扁，不偏不裁
4. **比例与清晰度**：宽度约占鞋底 1/4，黄黑对比锐利，丝网印刷贴花质感，几何形状完整可辨

**核验法**：HSV 黄度检测自动定位 bbox（`H∈[18,38] S>110 V>120` + 连通域 + 方形度>0.5），再与原图并排4× 放大 Read 对比——**别目视估坐标，这次先估裁歪了，改自动定位一次到位。**

### 打戏防伤化（第五集再次验证）

踹击/打斗场景提示词要写足四层，缺一层就会滑向暴力或滑向平庸：

| 层 | 写法 |
| --- | --- |
| 碎裂方式 | 只写**光粒与线条的崩散**（肥皂泡破裂 / 烟花熄灭 / 全息投影被拔电源），不写肉体形变 |
| 冲击表现 | 游戏式爽快 + 漫画式夸张：干净圆形冲击波环 + 放射状速度线 + 白色冲击闪光 |
| 姿态 | 狼狈滑稽（像被踢飞的布偶、手足乱蹬），**不是**庄严悲壮的神像陨落 |
| 表情 | 被打的虚影**保持憨厚傻笑**、无惊恐无痛苦 —— 喜感与角色气质同时保住 |
| 负面清单 | `不要血、不要伤口、不要淤青、不要骨裂、不要残肢、不要喷血、不要狰狞的痛苦表情` |
