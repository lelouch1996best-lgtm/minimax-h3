## 使用约定

1. **三视角必须同源**：正面／侧面／背面三视图为同一次生成产出，服装细节（纽扣数量、条纹、领带有无、鳞片斑纹）已锁定。跨集复用时**直传该三视图图槽**，不得重新描述服装，避免角色漂移。
2. **图槽防位移**（见 MEMORY 五·图槽防位移）：若该角色与其他角色同框，`<Subject N>` 编号顺序一旦变化，整片图槽会整体位移。新增同框角色前先核对图槽数量。
3. **表情控制**：基础形象即为「呆滞憨笑」，分镜中若需收敛表情，写「嘴角下垂、双眼半阖」，**不要**写「凶恶／狰狞／龇牙」——会破坏写实质感并有触发审核拒审的风险。
4. **色彩**：鱼头主色青灰绿 + 深色斑块；西装为黑（A）或藏青细条纹（B）。分镜描述肤色时用「青灰绿色湿润鱼皮」，不要写「肤色」。
5. **禁止项**：不要给该角色加鳍、鳞片延伸至手背、竖瞳、鱼尾——当前设定是「头部为鱼，身体完全人形」，破设定会直接崩形象。
6. **⚠️ 法天象地只认「线条虚影」两档**：实体版（雷暴天威 / 云海黄昏）已弃用。新项目引用法天象地形态时一律用 `法天象地（线条虚影·雷暴）.png` 或 `（线条虚影·云海）.png`。分镜描述该形态时写「半透明的青绿线条虚影、外缘化为飘散光点」，**不要**写「实体巨人／厚重的身体」。
7. **猴头分镜写作要点**：描述头部用「裸露的粉褐色脸 + 一圈深棕短毛」；**体型必须写「纤瘦高挑、九头身、肩窄、四肢修长」**（用户 2026-10-08 明确要求，不要写矮胖敦厚）；表情控制同大嘴鱼（写「嘴角下垂、双眼半阖」收敛，**禁写**凶恶/狰狞/龇牙）；要更呆滞可写「眯缝眼、咧嘴傻笑」。
8. **猴头三视角已核验**：五指完整无粘连、无画内文字、三视角西装/毛色/头身比一致。跨集复用**直传三视图图槽**，不要重新描述毛色/西装/体型。
9. **🔴 多主体同框时「最长那段会赢」**（2026-10-08 第五集踩坑）：主体（皮鞋+标识）与次要主体（虚影）同框，虚影的材质段写得最长就抢走了全图主描述权，成图里西装驳头线、双排扣纽扣线**全部消失**、鱼头巨嘴与傻笑糊成一团光丝，而鞋与标识完美。**「写了」不等于「模型会画」。** 对策：身份锁定提到提示词最前 + 显式排序（「先画X，再画Y，最后画Z」）+ 压缩材质段篇幅。完整配方见 `../素材包说明.md`「剧情场景图配方」。
