# 《漂亮的恶意·转校篇》E03 · 走廊连环计

生成一段15秒、16:9、2K、原生立体声的韩式校园剧喜剧高潮片段，核心概念是"三连恶作剧全数落空，幸运女生浑然不觉，反派自食其果"。

【人物锁定】南宫婉：十七岁中国转校生，纯黑及腰长发束高马尾半束发，珍珠中心银色双凤展翅发冠，额间金色火焰纹花钿清晰可见，双侧珍珠串坠耳环，深藏青修身校服西装外套（单排三金扣、左胸金色圆形校徽），纯白尖领衬衫，酒红格纹蝴蝶结领结，藏青底酒红格纹百褶短裙，白色中筒袜，黑色圆头低跟乐福鞋。紫灵：反派女生头目，高马尾编发冠，金色镂空发冠正中紫宝石，鼻至下颌覆半透明紫色面纱，紫罗兰眼眸，同款藏青校服。跟班A：栗棕色高双马尾、暗红发圈女生，同款校服。跟班B：灰黑齐下巴波波头、银色细框圆眼镜女生，同款校服。走廊远处另有泛化背景学生（喊话者）。

【0—15秒时间线】0—2.5秒：午后，暖金色阳光从走廊右侧大窗斜入，木地板镜面反光映着窗格与樱花枝；南宫婉抱着书从走廊一端走来；紫灵使眼色，三人组分头就位——跟班A闪身藏到立柱后预备伸脚，跟班B抱一摞书登上楼梯转角高处，紫灵端一盆清水埋伏在楼梯上方。2.5—5秒：南宫婉走近立柱瞬间，她马尾根部的珍珠发饰一颗松脱落地，她自然弯腰去捡，跟班A的脚恰好从她头顶上方伸过踢空，自己重心一晃闪了腰，扶柱龇牙。5—7.5秒：走廊尽头有同学用韩语喊"남궁완!"，她直起身转身挥手回应，跟班B推落的高高一摞书哗啦全倒砸在她身后空地，最上面几本弹起砸中探头的跟班B自己。7.5—10秒：紫灵在楼梯上倾盆倒水，一阵风恰好卷起几张传单掠过南宫婉面前，她偏头追着传单看，整盆水泼空，浇在正揉着腰冲过来的跟班A和跟班B头上，两人瞬间淋透。10—12.5秒：湿透的跟班A、跟班B和端着空盆下楼的紫灵在走廊中央狼狈撞成一团；南宫婉回头看到三人，礼貌性微微鞠躬，用韩语说"안녕하세요"，三人僵住。12.5—15秒：她转身哼着轻快的小调走远，午后阳光洒满背影，发冠与耳环反光；走廊中央三人组湿发贴脸、抱书的手都在抖，紫灵面纱上方的眼睛结冰般眯起，定格。

【表演与剪辑规则】三段恶作剧各自完成"设局—触发—落空—反噬"闭环；南宫婉的每次躲避由偶然事件驱动（发饰松脱、同学呼唤、风卷传单），全程无察觉；喜剧节拍逐次加快；结尾保留一秒三人组狼狈定格余波。

【视觉材质】走廊午后暖金主调、地板镜面反光、窗外樱花（春日幸运母题延续）；画面内不出现任何字幕与文字层。

【声音设计】走廊混响脚步，珍珠落地轻响，书本哗啦倾倒，泼水声与两人惊叫，南宫婉韩语问候清亮，走远时中文哼唱小调渐弱；弦乐拨奏三连喜剧点，结尾低音弦乐半秒收束。

【一致性收束】造型与前两集一致；三人组狼狈状态（湿发、闪腰、抱书）为E04路过窗外的连贯铺垫；飘落珍珠、传单、樱花构成贯穿幸运母题。
