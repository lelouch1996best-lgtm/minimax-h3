# 《漂亮的恶意·暗恋篇》E03 · 天台独白

@图片1作为南宫婉身份与服装参考@图片2作为紫灵身份与服装参考@图片3作为学校天台场景与阴沉天色参考
生成一段15秒、16:9、2K、原生立体声的韩式校园剧转折片段，核心概念是"嫉妒者终于正面出击，却被命运广播打断，独自吞下暴风雨"。

【人物锁定】南宫婉：同前（银凤冠、金色花钿、珍珠耳环、藏青校服酒红格裙）。紫灵：同前（紫面纱、紫宝石金冠、紫罗兰眼眸、酒红大蝴蝶结），本集面纱与发饰将成为雨景关键视觉元素。

【0-15秒时间线】0-2.5秒：午后，学校天台灰色天幕低垂预兆降雨；紫灵推开铁门，拽着南宫婉的手腕上了天台，用韩语说"너, 여기서 확실히 얘기해"，铁门在身后哐当合上。2.5-5秒：南宫婉被拽到天台中央，手腕被松开，她揉着手腕困惑地看着紫灵；紫灵背对铁门，面纱上方的紫罗兰眼眸逼视她。5-7.5秒：紫灵刚开口要说话，天台广播突然响起韩语"2학년 남궁완 학생, 교무실로 와주십시오"；南宫婉一怔，用韩语说"네, 가야겠다"，转身快步走向铁门。7.5-10秒：紫灵伸手要拦，但南宫婉已推开铁门快步下楼；铁门在紫灵面前砰然关上，她独自留在天台上，手伸在半空。10-12.5秒：天色骤暗，暴雨倾盆而下；紫灵站在雨中，紫色面纱湿透贴在脸上，金冠上紫宝石映着灰光，头发被雨水冲塌贴在面颊。12.5-15秒：她仰面朝天，雨水冲刷面纱，紫罗兰眼眸在雨中微微泛红；铁门内传来脚步声渐远，她攥紧拳头垂下，雨声渐强收束。

【表演与剪辑规则】紫灵的正面冲突按"拽上-松手-逼视-开口-被断-拦空-淋雨-仰面"情绪弧线展开；南宫婉的离场干脆利落不留犹豫，强化紫灵被抛弃的孤独感；广播打断是幸运母题的升级版（从自然元素到人为制度性运气）；暴雨是情感外化，面纱湿透是紫灵"面具被撕裂"的隐喻；结尾保留一秒雨中攥拳余波。

【视觉材质】天台灰冷主调（混凝土+铁丝网+灰天），与E01图书馆暖金、E02走廊青光形成天气弧递进；暴雨中面纱贴脸的特写是本集核心画面；紫宝石在灰雨中的微弱反光是角色识别锚点；画面内不出现任何字幕与文字层。

【声音设计】铁门推开与合上的金属哐响，紫灵拽手腕时布料摩擦声，广播喇叭电流底噪与韩语播报，南宫婉韩语回应清亮短促，铁门砰然关闭，暴雨由远及近的层次（先是雨点击铁丝网、再是倾盆白噪），面纱湿透后呼吸变闷，低音弦乐在攥拳时半秒收束融入雨声。

【一致性收束】南宫婉、紫灵造型与前两集一致；紫灵湿透状态（面纱贴脸、头发塌陷、金冠挂水珠）为E04窗后含泪的连贯铺垫；天台铁门与围栏为后续不再出现的封闭场景，本集独立完整。
