# 《漂亮的恶意·第三季·风云篇》制作方案

> 规格：6 集 × 15 秒（H3，16:9，2K，原生立体声，362 帧/集）
> 并发策略：2 批 × 3 并发（第1批 E01-E03，第2批 E04-E06）
> 审核节点：方案审核 → 剧本+payload审核 → API提交

---

## 一、故事概念

**风云篇**——韩立转学入校，沉稳气质打破现有格局。紫灵视其为可利用的棋子，韩立却对阴谋毫无兴趣。学校文化祭成为终极舞台：紫灵布下最危险的陷阱，韩立与玄骨从陌生到竞争、从各自为战到临时联盟，联手守护南宫婉。

"风云"双重含义：社交格局的风云变幻 + 文化祭压轴夜的风雨交加。

## 四、跨集锚点

1. **韩立-玄骨关系线**：走廊窗外对视(E01) → 球场目光交锋(E02) → 各自独立(E03-E04) → 走廊联盟(E05) → 联手救人(E06)，从陌生到默契的完整弧光。
2. **紫灵阴谋升级线**：发现棋子(E01) → 拉拢韩立失败(E02) → 指使偷窃(E03) → 嫉妒爆发(E04) → 物理陷害(E05-E06)，从社交手段升级到身体伤害。
3. **幸运母题延续**：韩立走廊撞见跟班鬼祟(E03)化解偷窃、南宫婉上台差点踩空被联手救下(E06)，延续前两季"巧合化解恶意"母题，但E06从"运气"进化为"有人守护"。
4. **天气弧**：午前清朗(E01) → 午后烈日(E02) → 课后阴沉(E03) → 白日室内(E04) → 傍晚暗沉(E05) → 夜风雨(E06)，天气镜像阴谋升级。
5. **声音母题**：低音弦乐嫉妒动机延续S1-S2全程；新增韩立主题（低沉钢琴单音，E01初现、E05联盟时双声部叠加）；E06结尾钢琴双声部完整奏响收束。
6. **对白规则**：南宫婉自语=中文（气声、温柔）；对话=韩语（带轻微口音）；韩立、玄骨、紫灵、凌玉灵、宋玉全部韩语；画面无字幕。
