# 《漂亮的恶意·暗恋篇》E02 · 鞋柜假情书

@图片1作为南宫婉身份与服装参考@图片2作为紫灵身份与服装参考@图片3作为跟班A身份与服装参考@图片4作为跟班B身份与服装参考@图片5作为学校走廊场景与课间光影参考@图片6作为玄骨身份与服装参考
生成一段15秒、16:9、2K、原生立体声的韩式校园剧喜剧片段，核心概念是"伪造情书的当众羞辱计划被一阵风吹成偶遇的缘分"。

【人物锁定】同第一季：南宫婉（银凤冠、金色花钿、珍珠耳环、藏青校服酒红格裙）、紫灵（紫面纱、紫宝石金冠、酒红大蝴蝶结）、跟班A（栗棕双马尾暗红发圈）、跟班B（波波头圆眼镜）、玄骨（黑发低马尾、右耳蓝穗耳坠、酒红领带）。走廊另有泛化背景学生若干。

【0-15秒时间线】0-2.5秒：课间，学校走廊鞋柜区白日青光，学生三三两两走过；紫灵快步将一封粉色信封塞入南宫婉鞋柜的缝隙，跟班A在侧望风、跟班B假装看书掩护，紫灵用韩语低声说"이번엔 절대 못 빠져나가"。2.5-5秒：南宫婉抱着作业本走来，到鞋柜前正要开门，但鞋带松了，她蹲下系鞋带；此时走廊窗户半开，一阵穿堂风将粉色信封从鞋柜缝隙吹出，信封飘飞到走廊转角。5-7.5秒：信封飘到走廊转角，被路过的玄骨随手接住；他低头看信封正面，上面手写"남궁완에게"四个字。7.5-10秒：南宫婉系好鞋带站起，打开鞋柜拿出室内鞋换上，浑然不觉；远处紫灵三人组屏息盯着--期待落空，跟班A的笑容僵住。10-12.5秒：玄骨走到南宫婉身旁，将信封递给她，用韩语说"이거 네가 떨어뜨린 것 같은데"；她惊讶接过，低头看信封，用中文轻声自语"信？谁给我的？"。12.5-15秒：紫灵面纱上方的眼睛缓缓眯起，指尖在鞋柜门上轻敲两下；跟班B凑到跟班A耳边低语韩语"또 실패했어"，两人交换眼神，定格。

【表演与剪辑规则】喜剧节奏按"预谋-期待-意外-反转"四拍结构；信封飘飞与鞋带松脱构成命运巧合的双重因果；南宫婉全程不知情，接到信时的惊讶来自"谁给我写信"而非"差点被害"；玄骨拣信递信让紫灵的陷害反而促成了两人第二次接触；切镜跟随事件触发（塞信、走来、蹲下、飘飞、拣信、递信、密谋）。

【视觉材质】韩剧质感白日青色调课间光，粉色信封在空气中飘飞的慢动作感，走廊窗户光柱中浮尘可见；画面内不出现任何字幕与文字层（信封上的字不可清晰辨认）。

【声音设计】课间走廊人声底噪，信封塞入鞋柜的轻响，风卷信封飘飞的沙沙声，玄骨接信时衣袖轻拂声，南宫婉中文自语为轻快气声，韩语对话低沉（玄骨）与带口音（南宫婉），紫灵指敲鞋柜门两声点题，轻快弦乐拨奏在信封飘飞处制造喜剧顿挫，结尾低音弦乐半秒收束。

【一致性收束】全员造型与第一季及E01完全一致（银凤冠、花钿、紫面纱、双马尾、圆眼镜、蓝穗耳坠）；信封道具粉色为贯穿本集关键道具；走廊场景与鞋柜位置与第一季E03走廊一致；结尾紫灵密谋眼神衔接E03天台正面冲突。
